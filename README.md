# Syntecxhub - NumPy Data Explorer

## Project 1 - Data Science Internship

This project was completed as part of the Syntecxhub Data Science Internship.

## Dataset

**Star Wars Characters Dataset**

The dataset contains information about Star Wars characters, including:

- Character
- Birthplace
- Age
- Affiliation
- Status

## NumPy Concepts Covered

- NumPy array creation
- Array indexing
- Array slicing
- Mathematical operations
- Axis-wise operations
- Statistical operations
- Array reshaping
- Broadcasting
- Saving NumPy arrays
- Loading NumPy arrays
- Performance comparison between Python lists and NumPy arrays

## Data Cleaning

The Age column contained different formats such as approximate values, ranges, unknown values, and text.

The values were cleaned and converted into numerical values where possible.

Invalid or unavailable age values were excluded from numerical calculations.

## Results

- Total rows: 94
- Total columns: 5
- Valid age values: 84
- Average age: 64.68
- Median age: 45
- Minimum age: 0
- Maximum age: 880
- NumPy performance speedup: 14.02 times
